# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short:

- Be respectful and considerate. Disagree about the work, not about the person.
- Harassment, personal attacks, discriminatory language and publishing others' private
  information are not accepted, in issues, pull requests, reviews, chat or anywhere else the
  project is discussed.
- Maintainers may remove, edit or reject contributions and comments that do not follow this,
  and may ban repeat offenders.

To report a problem, contact the maintainer, [@brandon-dacrib](https://github.com/brandon-dacrib),
privately on GitHub. Reports are handled in confidence.
